# Dockyard

An ongoing C# / .NET 10 rebuild of the legacy PHP Dockyard app located at [10ij/dockyard_legacy](https://github.com/10ij/dockyard_legacy).

## Overview

Dockyard is a specialized, ultra-lightweight web UI for managing Docker containers focusing on logs, status, and granular RBAC. This repository represents the active modernization of the original PHP stack into a clean, robust, and type-safe C# backend using ASP.NET Core MVC, Dapper, SQLite, and HTMX.

Features and documentation will be updated here incrementally as development progresses.
